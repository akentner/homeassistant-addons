Contract source: "Shared Contract C1-C13" in 24-01-PLAN.md (C2 options, C4 origins, C6 CLI, C9 context, C12 backups) and
`ntfy/app/contract.py`. DOCS promises (24-05 "Documentation facts" 1 and 2) are binding and repeated here as the
implementation rules:
1. Baseline user: created when missing with role `user` and origin `options`. An existing user keeps its origin and
   password unless `ctx.options.baseline_overwrite_passwords` is true (D-18): then `ctx.cli.user_change_pass(name,
   password)` runs for each existing non-admin baseline user at every start (password via `NTFY_PASSWORD` env only,
   origin unchanged, nothing created or deleted, the user is listed in `passwords_reset`, log line without the
   password). Users that are not named in the baseline (for example created in the GUI) are never affected.
2. Baseline rule (non-empty topic): permission `rw` when `write_access` is true else `ro`. No rule yet: set it, origin
   `options`. Rule exists with origin `options`: set it again only when the permission differs. Rule exists with origin
   `gui` or `iac`: keep it, count it as kept.
3. An empty topic creates only the user. An existing user with role admin gets no rules (warning). An entry whose
   username equals `admin_user` is ignored with a warning. Duplicate entries are processed in order.
4. After applying: every user or rule whose stored origin is `options` but that is not named by the current baseline gets
   origin `gui` (reported as orphaned); nothing is deleted.
5. Admin: created with role admin and origin `options` when the user is missing and `admin_password` is non-empty; an
   empty password logs a clear line and skips; an existing admin is left alone (password never overwritten).
Passwords go to the CLI only through the environment; log lines never contain passwords. Interfaces already in place
(24-01 tracer): `BootstrapReport`, `ensure_admin(ctx)`, `apply_options(ctx) -> BootstrapReport`, `main()`.
Parallel wave 3 plans own other files (24-08 calls `apply_options`); run only this plan's test files plus `test_contract.py`.

```python
@dataclass
class BaselineReport:
    users_created: list[str]; rules_set: list[tuple[str, str, str]]; rules_kept: list[tuple[str, str]]
    orphaned: list[str]; warnings: list[str]; passwords_reset: list[str]
def apply_baseline(ctx) -> BaselineReport
def ensure_admin(ctx) -> list[str]
def apply_options(ctx) -> BootstrapReport      # actions + warnings
def main() -> int                               # always 0 unless the context cannot be built
```
