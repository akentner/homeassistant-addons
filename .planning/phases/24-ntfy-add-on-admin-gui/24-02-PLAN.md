```python
class NtfyCliError(Exception):  # .code in {"exists","not_found","invalid","provisioned","locked","other"}; .message; .returncode
class NtfyCli:
    def __init__(self, binary: str, config_file: Path, auth_file: Path, timeout: float = 20.0) -> None
    def user_add(self, name: str, password: str, role: str = "user") -> None
    def user_change_pass(self, name: str, password: str) -> None
    def user_delete(self, name: str) -> None
    def user_change_role(self, name: str, role: str) -> None
    def access_set(self, user: str, topic: str, permission: str) -> None   # topic in CLI "*" form
    def access_reset(self, user: str | None = None, topic: str | None = None) -> None
    def token_add(self, user: str, label: str | None = None, expires: str | None = None) -> str
    def token_remove(self, user: str, token: str) -> None
class AuthDb:
    def __init__(self, path: Path) -> None
    def check_schema(self) -> SchemaStatus
    def ensure_supported(self) -> None
    def list_users(self, include_hash: bool = False) -> list[UserRow]
    def list_acl(self) -> list[AclRow]
    def list_tokens(self, user: str | None = None) -> list[TokenRow]
    def reveal_token(self, user: str, token_id_: str) -> str | None
    def snapshot_acl(self, user: str) -> list[AclRow]
    def counts(self) -> dict[str, int]      # users (without anonymous), acl_rules, tokens
    def size_bytes(self) -> int | None
    def has_user(self, name: str) -> bool
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API input -> CLI argv | user/topic/token/label/expires strings from the GUI reach a subprocess |
| auth.db -> API payloads | rows contain bcrypt hashes and clear-text tokens |
| GUI process -> auth.db | file shared with the running ntfy server (rollback journal) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-07 | Tampering | `NtfyCli` argv | high | mitigate | regex validation (no leading `-`, no `%`), list-form subprocess without shell, flags attached as `--label=v`; tests assert rejection before spawn |
| T-24-08 | Information disclosure | password handling | high | mitigate | `NTFY_PASSWORD` env only; fake log records only a boolean; test asserts the sample password never appears in argv logs |
| T-24-09 | Information disclosure | list payloads | high | mitigate | token column read only to derive id/prefix in-process; `reveal_token` is the only value path; test greps dumps for `tk_` values |
| T-24-10 | Denial of service | long-held read transaction | medium | mitigate | one short connection per call closed before processing; concurrency test against CLI writes |
| T-24-SC | Tampering | dependencies | low | accept | stdlib only in app code; tests use pytest/pyyaml via `uv run --with` (dev-time, not shipped) |
</threat_model>
