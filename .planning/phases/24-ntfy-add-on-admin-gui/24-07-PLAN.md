Contract source: "Shared Contract C1-C13" in 24-01-PLAN.md (C5, C6, C7, C8, C10) and `ntfy/app/contract.py`. Behaviour facts
promised by DOCS (24-05 "Documentation facts" 6 and 7) are binding. The precedence rule was verified against a real ntfy
2.36.0: stored rows `alice * ro`, `alice a_b* rw`, `alice pub1 deny`, `everyone x rw`, `everyone pub* ro` gave
publish results x 403 (user row beats everyone row), a_bz 200 (longest pattern), aXbz 403 (underscore is literal),
pub1 403 (exact deny), anonymous x 200, anonymous pub9 403; with rule `everyone pub* ro` an anonymous read of `pub9` gave
200 but of `PUB9` and `Pub9` gave 403 (matching is case-sensitive). ntfy's own ordering is
`user (non-everyone) first, LENGTH(stored pattern) DESC, write DESC`, stored pattern length counted in DB form
(`\_` is 2 characters). Parallel wave 3 plans own other files: run only this plan's test files plus `test_contract.py`.

```python
def effective(ctx, user: str, topic: str) -> Effective
def list_tokens(ctx, user: str | None = None) -> list[TokenMeta]
def create_token(ctx, user: str, label: str | None, expires: str | None) -> dict      # TokenMeta + "value"
def reveal_token(ctx, user: str, token_id_: str) -> str
def revoke_token(ctx, user: str, token_id_: str) -> None
def suggest(ctx) -> dict                                                                 # {"topic", "acl": [{"user","permission"}]}
```
