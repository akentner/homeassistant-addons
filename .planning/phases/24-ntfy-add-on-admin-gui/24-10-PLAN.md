<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API data -> DOM | user names, topics, labels are attacker-influenced (any ntfy user can set labels via CLI) |
| token values in browser memory | revealed on demand, copied by the admin |
| destructive buttons | one misclick must not wipe data |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-37 | Elevation of privilege (XSS) | all views | high | mitigate | htm text nodes only, static scan forbids raw-HTML APIs and dynamic code, mount tests render hostile-looking names without markup effects |
| T-24-38 | Information disclosure | token values | high | mitigate | list never carries values, reveal per row via POST, value kept in component state and dropped on Hide/unmount, never placed in URLs; test asserts the tree has no token-like string before reveal |
| T-24-39 | Tampering | accidental destructive actions | medium | mitigate | typed confirmation for user delete and the three resets (button disabled until exact text), protected rows disabled, danger zone separated |
| T-24-SC | Tampering | dependencies | low | accept | only the vendored, hash-pinned bundle from 24-04; no package manager |
</threat_model>
