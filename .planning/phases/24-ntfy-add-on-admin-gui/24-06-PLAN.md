Service interface produced here:

```python
def list_users(ctx) -> list[User]                      # everyone last; protection per C10
def create_user(ctx, name: str, password: str, role: str = "user") -> User
def change_password(ctx, name: str, password: str) -> None
def change_role(ctx, name: str, role: str) -> tuple[User, int]      # (user, dropped_rules)
def delete_user(ctx, name: str, confirm: str) -> None
def list_rules(ctx, user: str | None = None, topic: str | None = None) -> list[AclRule]
def set_rule(ctx, user: str, topic: str, permission: str) -> AclRule
def remove_rule(ctx, user: str, topic: str) -> None
```
Dependencies from other plans: `ctx.cli` (24-02), `ctx.db` (24-02), `ctx.origins`, `ctx.backups` (24-03),
`contract.api_error_from_cli` and `contract.token_meta_from_row` (24-01), `tests/helpers/ctx.make_context` (24-02).
`NtfyCliError` raised by a handler is converted to an `ApiError` by the router (C8); services let it propagate unless
they need a specific code.

      options `admin_user`, `last_admin` for the only other admin; counts reflect rules and tokens; origin comes from the store
    - `create_user("bob","pw")` makes bob (origin gui); existing name raises `ApiError` `conflict`; names `everyone`, `*`,

      over 72 bytes raises `bad_request`
    - `change_password` works for the options admin and the last admin, is refused for `everyone` (`bad_request`)
    - `delete_user("bob", "wrong")` raises `confirmation_required`; the options admin and the last admin raise `protected`;
      a successful delete creates a backup with reason `user-delete` first, removes the user and every origin record of it
    - `change_role` to the same role is a no-op returning `(user, 0)`; demoting the options admin or the last admin raises
      `protected`; promoting alice with two rules returns dropped 2, creates a `role-change` backup, leaves alice with no DB
      rules and a stash of both rules with their origins; demoting alice back restores both rules through the CLI with the
      stashed origins and empties the stash
    - `set_rule("alice","a_b*","rw")` stores the rule via the CLI with origin gui; editing a rule whose origin is `options`
      flips it to gui; a rule with origin `iac` keeps `iac`; unknown user raises `not_found`; an admin user raises
      `bad_request`; user `everyone` is allowed; permission outside PERMISSIONS or a bad topic raises `bad_request`
    - `remove_rule` of a rule that does not exist raises `not_found` (the CLI would report success); an existing rule is
      removed and its origin record dropped
    - `list_rules(user="alice")` filters; results carry origin; sorted by (user, topic)
    - mutations hold `ctx.lock`: two threads trying to demote the only two admins at once cannot both succeed
  </behavior>

  is the only admin-role user. `delete_user`: confirm must equal the name, protected users are refused, then
  `ctx.backups.create("user-delete")`, `ctx.cli.user_delete`, `ctx.origins.drop_user`. `change_role` per D-12 and spike
