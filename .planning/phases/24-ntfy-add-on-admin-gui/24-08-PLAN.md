| Boundary | Description |
|----------|-------------|
| ingress (HA admin) -> destructive routes | resets delete users, rules, messages |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24-28 | Denial of service / data loss | reset routes | high | mitigate | exact typed phrase server-side, backup before first change, `ctx.lock`, `reset_everything` refused without admin_password, admin recreated and verified |
| T-24-29 | Information disclosure | backup download | high | mitigate | gated route, names validated by regex and resolved-parent check, files 0600 |
