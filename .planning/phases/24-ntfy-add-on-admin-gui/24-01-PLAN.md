## C4 Origin sidecar `<data>/origins.json` (D-08; implemented by 24-03)

JSON object `{"schema": 1, "users": {"<name>": "<origin>"}, "acls": {"<user>": {"<topic*>": "<origin>"}},
"tokens": {"<user>": {"<token_id>": "<origin>"}}, "acl_stash": {"<user>": [{"topic", "permission", "origin"}]}}`.
Origin is one of `gui`, `options`, `iac`; absent means `gui`. User key `everyone` is the anonymous user, topics use the
CLI `*` form. `token_id` = first 12 hex chars of sha256(token). Writes: lock, temp file, `os.replace`, mode 0600. A
corrupt file is renamed to `origins.json.corrupt` and an empty store is used (warn, never crash).

## C5 Read model (AuthReader protocol; implemented by `AuthDb`, completed by 24-02)

Every read opens its own short-lived read-only connection (`file:...?mode=ro`, uri=True), runs one statement, closes;
never a held transaction (spike: a held read blocks CLI writes for 5 s). Missing file raises `ApiError(db_unavailable)`;
schema version != 10 raises `ApiError(db_unsupported)` from `ensure_supported()` which every read calls.
`%` (DB) maps to `*`, `\_` (DB) maps to `_`; DB user `*` maps to API user `everyone`.

- `SchemaStatus`: `{version: int|None, supported: bool, error: str|None}`
- `UserRow`: `{name, role ("admin"|"user"|"anonymous"), tier (tier code or None), provisioned: bool}` plus
  `pass_hash` only when `include_hash=True`; anonymous user appears as name `everyone`
- `AclRow`: `{user, topic (CLI "*" form), permission ("rw"|"ro"|"wo"|"deny"), read: bool, write: bool, provisioned}`
- `TokenRow`: `{user, token_id, prefix (first 7 chars), label, expires (unix s, 0 never), last_access (unix s),
  last_origin, provisioned}`; the token value is never in a row (D-13)
- methods: `check_schema()`, `ensure_supported()`, `list_users(include_hash=False)`, `list_acl()`,
  `list_tokens(user=None)`, `reveal_token(user, token_id) -> str|None`, `snapshot_acl(user)`, `counts()`,
  `size_bytes()`, `has_user(name)`; `permission` mapping rw=(1,1) ro=(1,0) wo=(0,1) deny=(0,0)

## C6 CLI adapter (`NtfyCli`, implemented core here, completed by 24-02)

`NtfyCli(binary, config_file, auth_file, timeout=20.0)`. Every call: `subprocess.run([binary, ...], stdin=DEVNULL,
capture_output=True, text=True, timeout=timeout)` with env = process env plus `NTFY_CONFIG_FILE` and `NTFY_AUTH_FILE`;
`NTFY_PASSWORD` only for password-taking calls and only in env, never argv (D-02, spike). Writes are serialized by a
class-level lock; `database is locked` is retried 3x with 1 s backoff. Exit 0 = success, 1 = any error: classify stdout
text into `NtfyCliError.code`: `exists` ("already exists"), `not_found` ("does not exist" / "not found"), `invalid`
("invalid argument" / "must be"), `provisioned` ("provisioned"), `locked`, `other`.
Methods: `user_add(name, password, role="user")`, `user_change_pass(name, password)`, `user_delete(name)`,
`user_change_role(name, role)`, `access_set(user, topic, permission)`, `access_reset(user=None, topic=None)`,
`token_add(user, label=None, expires=None) -> token value`, `token_remove(user, token)`. Topics are passed in the CLI
`*` form; user `everyone` addresses anonymous. Inputs are validated with the C7 regexes before spawning
(argv-injection guard); an empty password is rejected.

## C8 HTTP layer (`ntfy/app/web/server.py`)

- Gate first, for EVERY request (any method, any path, GET and static included): allowed only when
  `client_address[0] == ingress_remote` and a non-empty `X-Ingress-Path` header exists; otherwise 403
  `{"error":"ingress_only"}` (also for unknown paths, so 404 vs 403 leaks nothing).
- `Router.add(method, pattern, handler)`; pattern like `/api/users/{name}`; `{name}` is one URL-decoded segment
  (`unquote`, not `unquote_plus`); `Router.routes() -> list[(method, pattern)]`; unknown path 404
  `{"error":"not_found"}`, known path with other method 405 `method_not_allowed`.
- `Request`: `method, path, params (dict), query (dict[str, list[str]]), headers, json (parsed body or None)`;
  helpers `req.arg(name)` (first query value or None) and `req.body()` (JSON object or `ApiError(bad_request)`).
  Body read for POST, PUT, PATCH and DELETE only up to 65536 bytes (413 `payload_too_large` above), content type must
  be JSON when a body exists (this also forces a CORS preflight for cross-site requests).
- Handler return: `dict`/`list` gives 200 JSON, `None` gives 204, `(status, payload)` gives that status, `Download(
  filename, content_type, data: bytes)` gives an attachment. `ApiError(code, message)` becomes `{"error": code,
  "message": message}` with status from `ERROR_STATUS`; a `NtfyCliError` raised by a handler is converted with
  `api_error_from_cli(e.code, e.message)`; any other exception gives 500 `{"error":"internal_error"}`
  and a stdout traceback without request data.
- Static: `/` serves `static/index.html`, `/icon` serves `static/icon.png`, `/static/<rel>` serves any regular file
  below `static/` whose path segments each match `^[A-Za-z0-9_][A-Za-z0-9_.-]*$` (no leading dot, no `..`) and whose
  last segment has an extension in `mjs js css png svg txt`, resolved path inside STATIC_DIR (no symlink escape); content types
  `text/javascript; charset=utf-8`, `text/css; charset=utf-8`, `image/png`, `image/svg+xml`, `text/plain; charset=utf-8`.
  Static responses `Cache-Control: no-cache`, API responses `no-store`, always `X-Content-Type-Options: nosniff`, no
  frame-blocking header (HA embeds the page).
- API modules: every module in `ntfy/app/web/api/` that does not start with `_` exposes `register(router, ctx)`;
  `api/__init__.py:register_all(router, ctx)` imports them via `pkgutil.iter_modules` in sorted order and raises
  `RuntimeError` for a module without `register`. New API files are therefore picked up without editing a shared file.
- Error codes (`ERROR_STATUS`): bad_request 400, confirmation_required 400, ingress_only 403, not_found 404,
  method_not_allowed 405, conflict 409, protected 409, payload_too_large 413, ntfy_error 502, db_unavailable 503,
  db_unsupported 503, locked 503, internal_error 500. `ApiError(code, message, status=None)` lives in contract.py.
