<objective>
Put the ntfy admin GUI on the shared admin-ui lib, end to end, and build the scaffolding that lets the later plans
migrate views in parallel.

Prerequisite (D-01): execution starts only after Phase 24 is verified including the manual UAT on real HA ingress; that
UAT is also the visual reference for the accepted look change (D-09). This is a start condition for execution, not a
planning blocker. Executed in the worktree on branch `feat/ntfy-admin-ui-lib` (from current `origin/main`, D-12);
STATE.md, ROADMAP.md and state.json are never edited there. Commits: English, no Co-Authored-By line, stage by path.

Purpose: Task 1 is the tracer. It proves the thinnest complete path (copy the lib in with `make sync-admin-ui
ADDON=ntfy`, serve it through the existing server, load the page on lib tokens and the lib Preact, keep every existing
test green) before anything else is built on it. Tasks 2 and 3 expand: the shell on the lib, the string scaffolding with
de/en parity, the shared components, the shared test harness and the registry guards. Plans 27-02, 27-03 and 27-04 then
run in parallel on disjoint files.

Lib is copy-only (D-02, R-15): nothing under `ntfy/app/web/static/vendor/admin-ui/` or `ntfy/app/web/admin_ui/` and
nothing under `admin-ui/` is ever edited by hand. If ntfy needs something the lib lacks (D-03): do not fork or wrap
around it. Stop with a `checkpoint:decision` "request additive lib change from the admin-ui manager" (send the need with
`herdr agent prompt admin-ui "<need>"` to pane `wH:p1`), wait for the new lib version, then run
`make sync-admin-ui ADDON=ntfy` once while no other plan is running and commit the refreshed copies and
`admin-ui/lib.lock` separately. No such need was found while planning.

Shared-file ownership of this phase: `admin-ui/lib.lock` is maintained by the sync tool and expected unchanged; this plan
is the only one that runs `make sync-admin-ui`. `Makefile` and `.github/workflows/lint.yml` belong to plan 27-05 only.
`.pre-commit-config.yaml` needs no change (its admin-ui hooks already match `[^/]+/app/web/...`) and is owned by nobody.

Output: synced copies, shell on the lib, shims, string scaffolding, shared components, test harness, guards.
