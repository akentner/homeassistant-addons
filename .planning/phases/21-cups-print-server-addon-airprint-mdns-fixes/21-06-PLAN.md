## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HA add-on options (printers[], paperless_upload.queue_name) -> generate_config.py -> generated shell script -> lpadmin | User-controlled names/URIs become argv and echo text in a script executed as root |
| `lpstat -v` output of the old add-on -> migration helper stdout -> a YAML document the user pastes | Remote command output becomes YAML text |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-15 | Tampering (Injection) | widened PRINTER_NAME_RE (underscores, up to 127 characters) feeding lpadmin argv and generated echo lines | medium | mitigate | charset limited to [A-Za-z0-9_-] with fullmatch (no trailing newline); names still go through shlex.quote in argv; echo lines only print validated names; hardening tests cover space, slash, trailing newline and length boundaries |
| T-21-16 | Denial of Service | one failing lpadmin aborting registration of all later printers and the cups-pdf queue -- WR-09 | medium | mitigate | per-entry if/else with a WARNING and an aggregated exit status; Test 2 runs the real generated script against a failing stub lpadmin |
| T-21-17 | Tampering | migration helper emitting unescaped double quotes or backslashes from remote lpstat output into YAML scalars -- IN-06 | low | mitigate | escape before emission; Test 1 includes a URI containing a double quote and parses the result as YAML |
| T-21-SC | Tampering | npm/pip/cargo installs | low | accept | No package-manager install in this plan (shell, python stdlib; PyYAML is used only if already present and otherwise the check is skipped); the package-legitimacy gate is not triggered |
