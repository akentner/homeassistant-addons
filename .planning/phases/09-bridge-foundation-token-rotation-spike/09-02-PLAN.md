<objective>
Scaffold `terraform-provider-homeassistant/` as a Go 1.25 module that compiles against the Bridge via `replace`, and extend the existing version-management scripts (`internal/validate-versions.sh`, `internal/update-version.py`) to treat the Bridge + Provider as a single atomic release unit.

Purpose: Phase 9 needs the Provider scaffold in place so the Build Provider step in Phase 13 has a baseline to extend.
The Bridge and Provider share contract types via a `replace` directive (per D-03), so any Provider code drift fails
`go build`. The version-sync extension (per D-20/D-21) means a future
`make update-version ADDON=terraform-bridge VERSION=X.Y.Z` keeps both artifacts aligned in one command — the tag schema
`<addon>/v<version>` only fires for the Bridge (Provider is co-located, not add-on-tracked).

Output: 6 files total — 4 in the new Provider directory (main.go, go.mod, go.sum, build.yaml), 2 modifications to
repo-internal scripts. Phase 13 fills in `Configure`/resources/data sources without changing the directory layout.
</objective>
