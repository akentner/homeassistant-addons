  <name>Task 2: Create meridian/Dockerfile (multi-stage bun build + HA runtime)</name>
  <files>meridian/Dockerfile</files>
  <action>
Create a two-stage Dockerfile per D-01 through D-04.

**Stage 1 — Build (per D-01, D-02, D-03, D-04):**

```
FROM oven/bun:1 AS build

ARG VERSION
WORKDIR /build

# Download upstream source archive (per D-02 — tarball, no git clone)
RUN apt-get update && apt-get install -y --no-install-recommends curl tar && \
    curl -fsSL "https://github.com/rynfar/meridian/archive/refs/tags/v${VERSION}.tar.gz" \
    | tar xz --strip-components=1

# Install dependencies and build TypeScript
RUN bun install --frozen-lockfile
RUN bun run build
```

**Stage 2 — Runtime (per D-01, D-03, D-04):**

```
ARG BUILD_FROM=ghcr.io/home-assistant/amd64-base:3.22
FROM $BUILD_FROM

# Install Node.js and npm (per D-03: nodejs to run dist/cli.js, npm for @anthropic-ai/claude-code)
RUN apk add --no-cache nodejs npm

ARG VERSION
ARG WORKING_DIR=/opt/meridian

ENV WORKING_DIR=${WORKING_DIR}

# Install @anthropic-ai/claude-code globally to get the `claude` CLI binary (per D-03)
# DL3016 suppressed via hadolint ignore in .pre-commit-config.yaml (D-16)
RUN npm install -g @anthropic-ai/claude-code

# Copy compiled output and node_modules from build stage (per D-04 — no runtime reinstall)
COPY --from=build /build/dist ${WORKING_DIR}/dist
COPY --from=build /build/node_modules ${WORKING_DIR}/node_modules

# Copy run script
COPY run.sh ${WORKING_DIR}/
RUN chmod +x ${WORKING_DIR}/run.sh

WORKDIR ${WORKING_DIR}
CMD ["./run.sh"]
```

Then append the standard label block (copy verbatim from fritz-callmonitor2mqtt/Dockerfile lines 44-68).

- `/opt/meridian` as WORKING_DIR (consistent naming with fritz-callmonitor2mqtt pattern)
- `apt-get` in the bun stage (Debian-based), `apk` in the HA runtime stage (Alpine) </action> <verify>
