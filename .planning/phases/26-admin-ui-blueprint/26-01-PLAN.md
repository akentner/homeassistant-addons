<objective>
Tracer first: the thinnest production-quality path through every layer of the phase, then the add-on shell around it.
One request travels: Supervisor peer + X-Ingress-Path -> Python skeleton gate -> router -> `GET api/health` -> lib JSON
client (relative URL) -> vendored Preact -> Badge on the demo page. After that the add-on manifest, Dockerfile and a
Docker smoke script prove the same path in the real image.

Purpose: an architectural dead end (self-contained lib directory, relative-import-only skeleton, gate by peer address,
image built from `./admin-ui`) shows up after one commit instead of after twelve plans. This plan also freezes the
Shared Contract (names, signatures, formats) that the parallel wave-2 plans code against.

Output: skeleton package (final module layout, ntfy behaviour preserved), demo health page, lib seed (`api.mjs`,
`ui.mjs` subset, `vendor/`, `VERSION`), add-on manifest + Dockerfile + `run.sh`, scaffold tests, Docker verify script.

The tracer is deliberately cross-layer. To keep the authoring volume small, five files are copied byte-for-byte from ntfy
with shell `cp` (never retyped): `vendor/*`, `lib/api.mjs`, `tests/js/fakedom.mjs`.

### C2 Python skeleton API (`app.web.skeleton`, ntfy behaviour preserved)

| Module | Public names |
|--------|--------------|
| `errors.py` | `ERROR_STATUS` {bad_request 400, confirmation_required 400, ingress_only 403, not_found 404, method_not_allowed 405, conflict 409, protected 409, payload_too_large 413, internal_error 500}; `ApiError(code, message="", status=None)` (unknown code -> ValueError); `register_error_code(code, status)` (plan 02) |
| `router.py` | `Request(method, path, params, query, headers, json)` with `arg(name)`, `body()`; `Router.add(method, pattern, handler)`, `.routes()`, `.match(method, path)`; `Download(filename, content_type, data)`. Handler results: dict -> 200 JSON, `(status, dict)`, `None` -> 204, `Download` |
| `static.py` | `StaticFiles(root: Path)`, `.resolve(path) -> tuple[bytes, str] | None`; `/` -> `index.html`, `/icon` -> `icon.png`, `/static/<rel>`; `SEGMENT_RE`, `CONTENT_TYPES` (mjs js css png svg txt); containment by `resolve().relative_to(root)` |
| `ingress.py` | `INGRESS_REMOTE = "172.30.32.2"`; `is_ingress(peer, headers, remote=INGRESS_REMOTE)` = peer equals remote AND non-empty `X-Ingress-Path`; `ingress_user(headers)` (plan 02) |
| `headers.py` | `DEFAULT_CSP`, `security_headers(kind, csp)` (plan 02) |
| `server.py` | `MAX_BODY = 65536`; `make_handler(router, static, *, ingress_remote=INGRESS_REMOTE, server_version="AdminUi", csp=None, error_mappers=None)`; `make_server(router, static, port, *, ingress_remote=INGRESS_REMOTE, host="0.0.0.0", csp=None, error_mappers=None)`; `serve(server)` (plan 02) |

`StaticFiles` replaces ntfy's module-global `STATIC_DIR`. The gate runs first for every method and path (including HEAD and
OPTIONS); errors set `close_connection`; unexpected exceptions return `500 internal_error` with the traceback on stdout
only; `log_message` is silenced; API responses carry `Cache-Control: no-store`, static `no-cache`, all `nosniff`; no
`X-Frame-Options` on static files (the page is framed by HA).

### C3 Demo API (`app/web/demo_api.py`, `register(router, *, version, lib_version)`; plan 02 completes it)

`GET api/health` -> `{status:"ok", addon_version, lib_version}`; `GET|POST api/items`; `PUT|DELETE api/items/{id}`
(DELETE body `{confirm: <item name>}`, wrong or missing -> 400 `confirmation_required`; item `locked` -> 409
`protected`; duplicate name -> 409 `conflict`; invalid name -> 400 `bad_request`); `GET api/fail/{code}` (any
`ERROR_STATUS` code plus the demo-registered `teapot` 418); `GET api/slow?ms=` (clamped to 2000); `GET api/whoami`
(echo of `X-Remote-User-*`, plan 02 `ingress_user`); `POST api/echo`.

### C8 Distribution and enforcement (plan 06; wired by plans 09 and 12)

- Stamp `LIB.stamp` in every consumer copy: line 1 `version <X.Y.Z>`, line 2 `sha256 <tree hash>`, trailing newline.
  Tree hash = sha256 over sorted POSIX relative paths + NUL + sha256 of file bytes, skipping `LIB.stamp`, `__pycache__`,
  `*.pyc`; symlinks are refused.
- `admin-ui/lib.lock`: lines `version`, `lib`, `skeleton` (hashes of `lib/` and `skeleton/`).
- `python3 internal/sync-admin-ui.py [--root DIR] [--check] [--strict] [--all] [--addon NAME ...]`: no flag = refresh the
  lock only; `--addon NAME` copies lib to `<NAME>/app/web/static/vendor/admin-ui/` and skeleton to
  `<NAME>/app/web/admin_ui/` (creates the consumer); `--all` = every discovered consumer. Check outcome per PD-01. Exit 0

- Makefile: `sync-admin-ui` (`ADDON=<name>` optional), `check-admin-ui-sync`, `check-admin-ui-rules`, `test-admin-ui`.
