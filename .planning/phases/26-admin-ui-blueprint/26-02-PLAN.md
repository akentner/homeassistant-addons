<objective>
Harden the Python skeleton to the full blueprint server (security headers with a CSP switch, error-code registry, foreign
exception mappers, ingress user helper, `serve()` with signal handling) and complete the demo API that the demo GUI and
the spike page will call. Port ntfy's server test suite so the gate, router, body rules and static whitelist are enforced
by tests (D-16).

consumer exists. The demo API gives the GUI plans real endpoints for success, validation, conflict, protected,
type-to-confirm and every error state.

Output: `headers.py`, extended `errors.py`/`ingress.py`/`server.py`/`__init__.py`, full `demo_api.py`, `main.py` using
`serve()`, two test modules.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Docker network peer -> skeleton gate | only the Supervisor peer with `X-Ingress-Path` is trusted |
| Request headers/body -> handlers | method, path, query, headers, JSON body are all attacker-influenced |
| Handler exceptions -> response | internal error text must not cross to the client |
| `X-Remote-User-*` -> demo whoami | identity data of the viewer, set by the Supervisor |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-26-06 | Spoofing / Elevation | gate in `server.py` | high | mitigate | gate first for every method including HEAD/OPTIONS and unknown or traversal paths; table-driven gate tests; foreign-peer test |
| T-26-07 | Denial of service | `_read_body` | medium | mitigate | `MAX_BODY` 64 KiB -> 413, chunked and bad Content-Length -> 400, JSON object only, content type required |
| T-26-08 | Information disclosure | `ingress_user` / `api/whoami` | medium | mitigate | echo only to the requesting viewer, never log header values, values truncated; no wholesale header dump |
| T-26-09 | Tampering (XSS, MIME sniffing) | response headers | medium | mitigate | nosniff everywhere, CSP `script-src 'self'` on HTML/static with env switch, Referrer-Policy; CSP promise deferred to S9 (PD-07) |
| T-26-10 | Information disclosure | `log_message`, exception path | low | mitigate | request logging silenced (query strings can carry names), `internal_error` without text, traceback on stdout only |
| T-26-11 | Tampering (CSRF) | state-changing demo routes | medium | mitigate | mutating methods require `Content-Type: application/json` (not sendable by a plain cross-site form), ingress session cookie is SameSite=Strict (HA, H15), gate requires the Supervisor peer |
| T-26-12 | Denial of service | `api/slow` | low | mitigate | wait clamped to 2000 ms, threads are daemon threads |
| T-26-SC | Tampering | package installs | high | accept | No new packages; `uv run --with pytest` is the established test runner (ntfy); the CI pin is gated by the checkpoint in plan 26-09 |
</threat_model>
