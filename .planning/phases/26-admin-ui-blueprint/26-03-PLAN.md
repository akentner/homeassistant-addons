<objective>
Extract ntfy's `app.css` into the blueprint's `lib/base.css`: tokens (light, dark, explicit `data-theme`), base styles and
component classes, with the contrast defects of the ntfy palette fixed while extracting and locked by an automated
contrast test (PD-03). Add the theme-sync hooks (`var(--sync-*, default)`) so the optional module of plan 26-05 can
override tokens without touching the CSS.

Purpose: one stylesheet every admin GUI links; dark/light and a11y minimum (D-15) become test-enforced properties of this
file rather than review items.

Output: `lib/base.css` and `tests/test_css.py`.
