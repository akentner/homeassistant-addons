Semantics (PD-01, PD-04), per consumer part (lib copy and skeleton copy are checked independently):
1. source: hashes of `lib/` and `skeleton/` plus the VERSION must equal `admin-ui/lib.lock`, else FAIL (lock stale);
2. copy: recomputed tree hash must equal the stamp hash, else FAIL (tampered); for the lib part the copy's `VERSION` file
   must equal the stamp version;
3. same stamp version as the source: the stamp hash must equal the source hash, else FAIL (same version, different hash);
4. stamp version lower than the source: WARN "behind" (exit 0), FAIL with `--strict`; higher: FAIL "ahead".
Exit codes: 0 ok (warnings allowed), 1 drift, 2 usage or IO error. Without `--check`, no flag refreshes the lock only,
`--addon NAME` (repeatable) copies to that consumer (creating it), `--all` copies to every discovered consumer. Consumers
are top-level directories other than `admin-ui` that contain `app/web/static/vendor/admin-ui/LIB.stamp` or
`app/web/admin_ui/LIB.stamp`. Add-on names must match `^[a-z0-9][a-z0-9_-]*$`, must not be `admin-ui`, and the directory
must exist and contain `config.yaml`.
