Intl-based formatters, and the i18n mechanics with the base string tables (de/en), each with node tests. ntfy's API
client tests are ported; the gaps ntfy never had (i18n, locale-correct formatting, storage resilience) are closed here.

Purpose: D-08/D-09/D-10 make de/en a blueprint property, not a per-add-on option; the parity and used-key scans make
"every user-visible string is translated" an enforced rule instead of a convention.

Output: `hooks.mjs`, `ingress.mjs`, `format.mjs`, `i18n.mjs`, `strings.{de,en}.mjs` and five node test files.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage on HA's origin | the same storage holds HA's own data; the add-on page shares it |
| Backend error body -> UI | `error` codes and `message` text come from the add-on server |
| i18n parameters -> DOM | values (names, codes) are interpolated into UI text |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-26-16 | Tampering / Information disclosure | `i18n.mjs` storage access | medium | mitigate | single namespaced key `admin-ui:lang`, only the values `de`/`en` are ever read back, access in try/catch with `typeof` guards, never log or echo storage contents; tests with throwing and absent storage |
| T-26-17 | Tampering (XSS) | `t()` interpolation, `tError` | high | mitigate | `t()` returns plain strings that components render as text nodes; tests prove `<b>` stays literal; dynamic keys forbidden by the used-key scan; `tError` never uses the backend `message` |
| T-26-18 | Spoofing / Information disclosure (request forgery to other origins) | `api.mjs`, `ingress.mjs` | medium | mitigate | `buildUrl` rejects absolute, scheme and empty paths; `assertRelative` and `apiHref` reuse the rule; ported tests cover it |
| T-26-19 | Information disclosure | error rendering | low | mitigate | UI shows localized text by code and the code in brackets; the English backend message is not displayed as primary text (Pitfall 9) |
| T-26-SC | Tampering | package installs | high | accept | No package installs in this plan (stdlib and the vendored bundle only) |
</threat_model>
