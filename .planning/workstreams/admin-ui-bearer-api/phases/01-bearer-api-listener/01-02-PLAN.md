<objective>
Make both servers share one JSON stack and run in one process, and complete the API's request handling (D-02, D-04).

Purpose: After plan 01 the API handler already uses `_JsonHandler`, but the ingress handler still carries its own copy
of the helpers, and a consumer cannot run both servers with one signal handler. This plan moves GuiHandler onto the
shared base (guarded by the characterisation test written in plan 01), adds `serve(server, *more)`, and proves every
request-handling rule of D-04 on the API port: body limits and parsing, error codes, response kinds, headers, no static
files and no CORS, explicit IPv4 bind, no public routes, socket timeout.

Output: refactored `server.py`, completed `api.py`, extended `tests/test_api_server.py`, refreshed `lib.lock`.
</objective>
