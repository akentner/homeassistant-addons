<objective>
Close every path around the bearer gate (D-05): unknown methods, parser errors, HTTP/0.9, every malformed or misplaced
credential, and keep-alive after an unread body all end in the one identical 401.

Purpose: A stdlib `BaseHTTPRequestHandler` answers unknown methods with an HTML 501 and parser errors with HTML
400/414/431/505 before any handler code runs (RESEARCH Pitfalls 2-5). Without this plan the gate covers only the seven
bound methods and well-formed requests, which contradicts AUB-02 ("every method and path ... identical response for all
failure cases").

Output: hardened `api.py` (`__getattr__`, `send_error`, HTTP/0.9 rule, `_verified`, strict `_bearer_token`), raw-socket
tests in `tests/test_api_server.py`, refreshed `lib.lock`.
</objective>
