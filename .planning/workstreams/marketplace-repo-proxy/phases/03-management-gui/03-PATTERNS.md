## Pattern Assignments

### `app/gui.py` (entry, request-response)

**Analog:** `ntfy/app/gui.py` (lines 1-45), combined with options handling from `marketplace-repo-proxy/app/watch.py:74-103`.

Core wiring to copy (ntfy `gui.py:31-41`):

```python
def main() -> int:
    ctx = build_context()
    logging.basicConfig(...)
    router = Router()
    register_all(router, ctx)
    port = int(os.environ.get("NTFY_GUI_PORT", str(GUI_PORT)))
    server = make_server(router, port, os.environ.get("NTFY_INGRESS_REMOTE", INGRESS_REMOTE),
                         csp=csp_from_env(os.environ))
    print(f"[gui] listening on port {port}", flush=True)
    serve(server)   # from app.web.admin_ui: handles SIGTERM shutdown
    return 0
```

Adaptation for MRP (D-07): no container env, so no `os.environ` lookups for secrets. Load options like `watch.py:82-91`
and drop the credential before building the service:

```python
paths = paths or Paths.default()
try:
    options = load_options(paths.options_file)
except OptionsError as exc:
    setup_logging("info")
    LOG.error("%s", exc)
    return 1
# keep only what this service needs; the credential is not used here
specs, log_level = options.repositories, options.log_level
del options
setup_logging(log_level)
```

For the GUI, keep an `Options` copy with `github_token=""` (RESEARCH Pattern 1: `dataclasses.replace(options,
github_token="")`) because `app/urls.py:26 store_urls(options, hostname, ...)` needs `public_url`. Use
`app.logsetup.setup_logging` (redacts 32-hex), not `logging.basicConfig`. Guard `if __name__ == "__main__": sys.exit(main())`.

### `app/web/server.py` (router + server adapter)

**Analog:** `ntfy/app/web/server.py` (whole file, 44 lines). Copy shape:

```python
from app.web.admin_ui import DEFAULT_CSP, Request, Router, StaticFiles
from app.web.admin_ui import make_server as skeleton_make_server

STATIC_DIR = Path(__file__).resolve().parent / "static"

def make_server(router, port, ingress_remote=INGRESS_REMOTE, host="0.0.0.0", static=None, csp=DEFAULT_CSP):
    return skeleton_make_server(router, StaticFiles(STATIC_DIR) if static is None else static, port,
                                ingress_remote=ingress_remote, host=host, csp=csp,
                                error_mappers={NtfyCliError: _cli_error})
```

MRP: `error_mappers={AccessError: _access_error}` mapping `exc.code` (Phase 1 codes, `app/access.py:39-45`) to the
skeleton's `ApiError` (check the exact class in `ntfy/app/web/admin_ui/__init__.py` exports). Since MRP has few routes,
put `build_router(service) -> Router` in this file instead of ntfy's `api/` package + `register_all`
(`ntfy/app/web/api/__init__.py`). Handler style from `ntfy/app/web/api/users.py:11-35`:

```python
def _strict_body(req: Request, allowed: set[str]) -> dict[str, Any]:
    body = req.body()
    unknown = set(body) - allowed
    if unknown:
        raise ApiError("bad_request", f"unknown field: {sorted(unknown)[0]}")
    return body
...
router.add("GET", "/api/users/{name}", handler)   # path params via req.params["name"]
handler returns dict -> 200, (201, dict) -> status, None -> 204
```

Confirm-before-destroy (D-12): server re-checks `body["confirm"] == user` and raises a stable code (e.g. `confirm_mismatch`).

### `app/web/service.py` (service, CRUD under lock)

**Analog:** `marketplace-repo-proxy/app/cli.py:87-145`. The GUI service is the CLI's commands as functions returning
dicts instead of printing.

```python
# add (cli.py:103-110)
spec = options.find(args.repository)
if spec is None:
    return _error("repository_unknown")
entry = AccessStore(paths).add(spec.slug, args.user, source="cli", hash_=args.hash_, specs=options.repositories)
# -> GUI: source="gui"

# revoke (cli.py:128-135): unconfigured repositories can be revoked too
repository = spec.slug if spec is not None else args.repository
if not AccessStore(paths).revoke(repository, args.user, specs=options.repositories): -> "user_unknown"

# sync trigger (cli.py:138-145)
if not paths.run_dir.is_dir():
    paths.run_dir.mkdir(parents=True, exist_ok=True)
    paths.run_dir.chmod(0o700)
atomic_write_json(paths.trigger_file, {})

# list with masking + inactive flag (cli.py:87-101)
masked = mask_hash(hash_) if isinstance(hash_, str) and HASH_RE.fullmatch(hash_) else "<invalid>"
active = isinstance(repository, str) and options.find(repository) is not None
```

Rotate (D-11, D-10: no change to `access.py`): compose inside one `with store.locked():` (reentrant,
`access.py:84-104`): `entry = store.get(...)`, `store.revoke(..., specs=None)`, `store.add(..., source=entry["source"],
specs=specs)`. `locked()` is reentrant within the thread, so nested `get/revoke/add` do not deadlock. Refuse
`source == "system"` before mutating (D-13). Overview reads `app/status.py:26 read_status(paths)` (returns None when
missing -> "no status yet", D-17).

def read_status(paths: Paths) -> dict | None:

### `app/fetchlog.py` (s6 longrun, root, writes `/data/last-fetch.json`)

**Analog:** `app/watch.py` (lines 1-108): module docstring naming the service and contract, `main(argv, paths)`
signature for tests, `argparse` with `RawDescriptionHelpFormatter`, SIGTERM/SIGINT -> `threading.Event`, loop
`while not stop.is_set(): ...; stop.wait(interval)`:

```python
stop = threading.Event()
def _stop(*_: Any) -> None:
    stop.set()
for sig in (signal.SIGTERM, signal.SIGINT):
    signal.signal(sig, _stop)
```

Error logging must be content-free (`watch.py:58`: `"%s", type(exc).__name__`), never the hash. Writes via
`app/jsonio.py:12 atomic_write_json` (mode 0600, atomic, dir fsync) and timestamps via `utc_timestamp()`. Document has a
`schema` field like `access.json`/`status.json` (`status.py:17 SCHEMA = 1`). Single writer (D-21).

## Shared Patterns

### Secret hygiene / no container env
**Source:** `s6-rc.d/access-watch/run`, `s6-rc.d/lighttpd/run`, `app/watch.py:88-90`
**Apply to:** `gui`, `fetchlog`, fetchsink: `#!/bin/sh`, no `with-contenv`, drop `github_token`; logs via
`app.logsetup.setup_logging` (32-hex redaction); error logs only `type(exc).__name__`.

### Atomic JSON contract files
**Source:** `app/jsonio.py:12-30` (`atomic_write_json`, mode 0600) and `read_json` (None when missing)
**Apply to:** `last-fetch.json`, `sync.request`, any GUI write.

### Stable error codes
**Source:** `app/access.py:39-45` `AccessError(code)`; CLI `_error(code)` (`cli.py:71`)
**Apply to:** server error mapper; reuse `repository_unknown`, `user_exists`, `user_unknown`, `invalid_user`,
`user_reserved`; strings tables carry a translation per code.

### Locked access store
**Source:** `app/access.py:84-104` reentrant `locked()`, `add`/`revoke` with `specs=` reconcile inside the lock
**Apply to:** `service.py` add/revoke/rotate.

### admin-ui lib consumption
**Source:** `Makefile:110-122` (`sync-admin-ui`, `check-admin-ui-sync`, `check-admin-ui-rules`)
**Apply to:** first plan task runs `make sync-admin-ui ADDON=marketplace-repo-proxy`; vendor copies never hand-edited.
