## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin browser (via ingress) → access routes | State-changing requests that create, destroy and replace capabilities |
| GUI process → `/data/access.json` + symlink tree | Shared with CLI, access-watch and fetchlog under one lock |
| access routes → browser | Store URLs are capabilities; any response that carries them is sensitive |

| T-03-16 | Information disclosure | Store URLs in list or poll responses, logs or tracebacks | high | mitigate | URLs only from the on-demand route and the add/rotate responses; list and overview hold no hash or URL (pytest + container needle checks); logs name labels only; OSError/AccessError mappers suppress tracebacks; `Cache-Control: no-store` |
