## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HA ingress proxy → GUI server (port 8099) | Only the Supervisor's ingress peer with `X-Ingress-Path` may reach the page; any other peer on the `hassio` network is untrusted |
