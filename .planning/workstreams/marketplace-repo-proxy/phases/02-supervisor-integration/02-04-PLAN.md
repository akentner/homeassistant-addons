## Confirmed decisions and assumptions (for user confirmation)

Locked decisions implemented: D-09 (add first, then try to remove; refusal reported, never forced, never looped),
D-10 (leftover recorded and logged at warning).

Open question planned with the recommended variant (confirm or correct):

- **Q-2 Old `local` URL after rotation:** the retired entry `local.{old slug}` keeps serving while its store repository
  is a leftover, so installed add-ons keep getting updates until they are reinstalled from the new store repository;
  it is revoked when the DELETE succeeds, returns 404, or the slug disappears from the store. `--revoke-old` is the
  escape hatch for a leaked URL (cuts updates for still-installed add-ons, uninstalls nothing). This deviates from the
  SPIKE sentence "the old URL stops working right away", which was written for consumer users, not for the `local` user.

Planner assumptions:

- **A-11 Rollback:** a failed add of the new URL rolls the rotation back; there is never a state where the old URL is
  removed before the new one is registered.
- **A-12 Leftover detection is report-only:** `interrupted` and `orphaned` leftovers are never deleted automatically,
  including after a hostname change (an add-on installed from the old URL may still exist).

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-20 | Tampering | forced removal or uninstall of add-ons during rotation | high | mitigate | Only `DELETE /store/repositories/{old slug}` after a successful add; refusal recorded, never retried; no uninstall endpoint in the allow-list; tests assert request order and DELETE counts |
| T-02-21 | Information disclosure | old (possibly leaked) `local` URL keeps serving after rotation | medium | mitigate | Leftover visible in supervisor.json, `mrp local status` and the log; `--revoke-old` cuts it at once; revoked automatically when the store repository is gone (Q-2 assumption documented in Plan 06) |
