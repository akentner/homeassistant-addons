`app/supervisor.py` (per D-02, D-03, D-04; RESEARCH Pattern 1 and "Supervisor store API contract"): module docstring says it is the only module that talks to the Supervisor, over the TCP API with the add-on token, and that the transport lives in one private method so a Unix-socket transport can replace it later (assumption Q-6). Constants and types exactly as in `<interfaces>`. `SupervisorClient.call` validates before any I/O, in this order: `(method, template)` in `ALLOWED` (exact string compare, so lower-case methods and near-miss paths fail) else `SupervisorRefused("not_allowed")`; for the `{slug}` template the slug must be a `str` with `SLUG_RE.fullmatch` else `invalid_slug`; empty token -> `token_missing`; a body only on POST of `/store/repositories` and only a `dict` -> else `invalid_body`. Build the request with `urllib.request.Request(base + path, data=..., method=method)`, `add_unredirected_header("Authorization", "Bearer " + token)`, `Content-Type: application/json` only with a body; open through one opener built with `urllib.request.build_opener(urllib.request.ProxyHandler({}), <a redirect handler whose redirect_request returns None>)` so proxy env vars are ignored and a 3xx comes back as an error result; timeout from `TIMEOUTS`; read at most `MAX_BODY` bytes. `HTTPError` -> parse its status and body; `TimeoutError`/`socket.timeout` -> `CallResult(False, 0, message="timeout")`; `URLError`, `http.client.HTTPException`, other `OSError` -> `CallResult(False, 0, message="unreachable")` (never `str(exc)`, it can carry the URL). Parsing: a JSON object with `result == "ok"` -> `ok=True` with `data`; with `result == "error"` -> `ok=False`, `error_key` (str or None), `message = mask_text(message)`; any other body (plain-text 401/403 from the middleware, empty, non-JSON, 2xx without the envelope) -> `ok=False` with the status and an empty message. `mask_text(text, limit)`: replace every `/repo/{owner}/{repo}/{32 hex}` (owner/repo = runs without `/`, whitespace or quotes) with `/repo/{owner}/{repo}/` + `urls.mask_hash(...)`, then return `gitops.sanitize(text, limit)`. `read_token(environ)` returns the first non-empty value of `TOKEN_ENVS`, stripped. `store_slug(url)` = `hashlib.sha1(url.lower().encode("utf-8")).hexdigest()[:8]`. Logging (logger `mrp.supervisor`, D-04): exactly one line per sent request, `supervisor %s %s: %s` with method, template and the status (or `timeout`/`unreachable`), info for 2xx, warning otherwise; refused calls (`SupervisorRefused`) log one warning `supervisor call refused: {code}` and send nothing. Never log the filled path, the body or the response. `__repr__` shows the base only; the token lives in a private attribute.
