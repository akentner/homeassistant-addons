<task type="auto">
  <name>Task 2: Update run.sh — oauth polling flow and meridian invocation</name>
  <files>meridian/run.sh</files>
  <action>
    Rewrite the credential check section and the final exec. Keep the symlink logic unchanged.

    New credential check flow:

    ```bash
    # If credentials missing: start claude login (prints OAuth URL to stdout/stderr → HA logs)
    if [[ ! -f /data/.claude/.claude.json ]]; then
        bashio::log.info "Claude credentials not found. Starting OAuth login..."
        bashio::log.info "Check the add-on logs for an OAuth URL, open it in your browser to authenticate."

        # Run claude login in foreground — it prints the OAuth URL and waits for browser completion
        # Claude Max OAuth does not require interactive TTY; URL appears in logs
        claude login &
        LOGIN_PID=$!

        # Poll until credentials file appears (up to 10 minutes, check every 5 seconds)
        TIMEOUT=600
        ELAPSED=0
        while [[ ! -f /data/.claude/.claude.json ]]; do
            sleep 5
            ELAPSED=$((ELAPSED + 5))
            if [[ $ELAPSED -ge $TIMEOUT ]]; then
                bashio::log.error "OAuth login timed out after ${TIMEOUT}s. Restart the add-on to try again."
                kill "$LOGIN_PID" 2>/dev/null || true
                exit 1
            fi
            bashio::log.info "Waiting for OAuth completion... (${ELAPSED}s elapsed)"
        done

        bashio::log.info "Credentials found. Proceeding to start Meridian."
        # Give claude login a moment to finalise writing, then kill the process if still running
        sleep 2
        kill "$LOGIN_PID" 2>/dev/null || true
    fi
    ```

    Keep the config reads (log_level, port) and exports (MERIDIAN_LOG_LEVEL, MERIDIAN_PORT, MERIDIAN_HOST) unchanged.

    Replace the final exec line:
    - OLD: `exec node "${WORKING_DIR}/dist/cli.js"`
    - NEW: `exec meridian`

    The `meridian` global binary handles --port / --host via environment variables MERIDIAN_PORT, MERIDIAN_HOST,
    MERIDIAN_LOG_LEVEL (set by the exports above). No flags needed if env vars are honoured by the CLI.

    Keep the shebang (`#!/usr/bin/with-contenv bashio`) and shellcheck directive (`# shellcheck shell=bash`).
    Keep the symlink block (`mkdir -p /data/.claude` + `ln -sf /data/.claude /root/.claude`).

  </action>
