## D-06 — Reflow-proof gate technique: flatten, then grep a phrase.

A multi-word literal can be split across two lines by prettier, which silently breaks `grep -F`. Every
prose gate below therefore flattens its input first:

```
F=$(tr '\n' ' ' < "$f" | tr -s '[:space:]' ' ')
h(){ printf '%s' "$F" | grep -qF -- "$1"; }
```

Region-scoped assertions extract the region with `sed -n '/^## Heading$/,/^## Next$/p'` and flatten
that. Both forms were executed against the tree at `ba490aa`: the target-polarity chains are RED, the
invariant chains are GREEN. Note the two `tr` calls contain no `*`, deliberately — `.prettierignore`'s
own header records that prettier turns `'^[[:space:]]*#'` into `'^[[:space:]]_#'`, a filter that still
looks correct. `.planning/` is prettier-ignored so this plan is safe either way; the gates avoid `*`
anyway.

comment lines, and the toolchain a tracer would validate (edit -> prettier reflow -> markdownlint ->
re-measure anchors) is **already measured green at baseline** (`pre-commit run --files` on both docs,
